# CUA Full Ablation — baseline ReAct vs full harness (67 tasks)

Date: 2026-09-02. Real models: `deepseek-chat` (DOM/text) for non-vision tasks,
`qwen3-vl-flash` (DashScope) for the 15 vision-required tasks. `use_vision="auto"`
so the vision model gets screenshots and the text model does not.

**67/67 tasks ran** (134 runs: baseline + full for each). Token cost: **$0.23**.

## Headline

| Metric | Baseline (recovery off) | Full (recovery on) | Delta |
| ------ | ----------------------- | ------------------ | ----- |
| Success rate | 85.1% (57/67) | 91.0% (61/67) | **+6.0pp** |
| Invalid action rate | 1.02% | 0.85% | −17% relative |
| Recovery success rate | — | 33.3% (1/3) | — |
| Avg steps | 3.7 | 4.5 | — |
| Avg latency | 8.6s | 20.8s | — |
| Avg tool calls | 4.4 | 5.3 | — |

## Composition

- **67 tasks** = 46 original + 15 vision-required (color / icon / image-text /
  SVG geometry / real-photo recognition) + 6 long-horizon (20–40+ steps).
- **Recovery wins (fail → pass):** 4 tasks — `multi_step_wizard`,
  `rerender_reshuffle_buttons`, `rerender_reveal_stepper`, `wizard_expanding_steps`.
- **Fail in both modes:** 6 tasks — 5 long-horizon
  (`account_setup_wizard`, `ecommerce_checkout_flow`, `cross_page_data_collection`,
  `project_setup_crud`, `settings_panel_wizard`) + `read_image_number`.

## Breakdown by category (full mode)

- **Vision-required (15):** 14/15 pass. `qwen3-vl-flash` recognizes colors, icons,
  SVG shapes, and real photographs; it fails `read_image_number` (reading "42"
  out of a rendered PNG).
- **Long-horizon (6):** 1/6 pass (`conditional_registration`, the shortest).
  `deepseek-chat` exhausts its step budget or returns "no tool calls" on the
  20–40 step multi-page flows — a genuine model ceiling, not a harness gap.

## Notes

- The success-rate delta is smaller than the earlier 46-task run (+13pp) because
  the new failure modes (long-horizon "no tool calls", a vision OCR miss) are not
  stale-element recoveries — they are model-capability limits the recovery ladder
  is not designed to fix.
- Recovery attempts are rare (3) because `deepseek-chat`'s dominant failure is a
  format/empty output, not a stale index.
- `qwen3-vl-flash` emits raw-coordinate clicks (no `index`) on some geometry
  tasks; the `click` schema requires `index`, so those are rejected and
  re-queried, inflating latency on `click_red_circle` (~6.6 min) but not
  changing its final success.
